# Bundled font: Inter (variable)

- Version: Inter 4.001 (Google Fonts "v20" static snapshot of the Inter 4.x variable font).
- Source: https://fonts.google.com/specimen/Inter — CSS `family=Inter:wght@100..900`, "latin" subset.
- Direct file: https://fonts.gstatic.com/s/inter/v20/UcC73FwrK3iLTeHuS_nVMrMxCp50SjIa1ZL7.woff2
- Upstream project: https://github.com/rsms/inter (released v4.1; the master branch is at 4.2).
- File: `inter-latin-variable.woff2` (48,256 bytes), variable weight axis 100–900, normal style.
- Embedded name record: `Inter-RegularVersion 4.001`. The file is a variable font; the
  default instance is Regular but `font-weight` works across the whole 100–900 range.
- Coverage: the Google Fonts "latin" unicode range — U+0000–00FF (includes `×` U+00D7 and
  `·` U+00B7), U+0131, U+0152–0153, U+02BB–02BC, U+02C6, U+02DA, U+02DC, U+0304, U+0308,
  U+0329, U+2000–206F (includes `…` U+2026), U+20AC, U+2122, U+2191, U+2193, U+2212,
  U+2215, U+FEFF, U+FFFD. Arrows and other glyphs outside this range are drawn as SVG, so
  no symbol ever depends on a system fallback.
- Use: Light (300) for hints, Medium (500) for body text, Bold (700) for emphasis.
- Licence: SIL Open Font License 1.1 — `licenses/INTER_OFL-1.1.txt`
  (https://raw.githubusercontent.com/rsms/inter/master/LICENSE.txt).

This is the only font file the extension ships. No font is loaded from the internet.
